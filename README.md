# 나이스리모컨 (다운로드)

교육청을 한 번만 고르면 나이스·업무포털·K-에듀파인을 버튼으로 열고, 로그인한 뒤에는 자주 쓰는 메뉴를 버튼 하나로 여는 Windows 프로그램이에요. made by 문수네집

예전 이름은 '나이스자동리모컨'이에요. 시험판 0.5.0-beta.10부터 '나이스리모컨'으로 바뀌었고, 설정·즐겨찾기는 그대로 이어져요.

## 받는 방법
1. [릴리스 목록](https://github.com/moonsugugu/neis-launcher-download/releases)에서 `NEIS-Remote-Eduitit-Setup-<버전>.exe`를 내려받아요.
   - 지금 버전: [ver. 2.0.1 바로 받기](https://github.com/moonsugugu/neis-launcher-download/releases/download/v2.0.1/NEIS-Remote-Eduitit-Setup-2.0.1.exe)
2. 받은 파일을 실행하면 설치돼요. 관리자 권한은 필요 없어요.

처음 실행할 때 Windows가 "PC를 보호했습니다"를 띄우면 **추가 정보 → 실행**을 누르세요. 서명이 없는 프로그램이라 나오는 경고예요.

나이스·업무포털은 학교 교육망 안에서만 열려요. 로그인은 각 교육청 화면이 처리하고, 이 프로그램은 아이디·비밀번호를 저장하지 않아요.

## 버전
- **ver. 2.0.1**: 선생님들이 알려 주신 오류를 고쳤어요. 로그인 전에 다른 버튼을 누르면 ⏻ 업무포털 로그인부터 알려 줘요(미니 모드는 교육청 고르기 줄이 내려오고, 큰 화면은 ⏻가 깜빡여요). 껐다 켠 뒤 K-에듀파인이 안 열리던 것(업무포털에서 눌러도, 기안·공람·품의 버튼을 눌러도 반응이 없던 것)과, 공문/품의·가정통신문 메이커가 Google 로그인 뒤 새로고침해야 뜨던 것을 고쳤어요.
- **ver. 2.0 (2.0.0)**: 시험판 번호를 마치고 정식 번호로 낸 첫 판이에요. 출결·누가기록 넣기, 미니 모드 기본, 접기 모드(막대 꽉 참·창 크기 오류 고침), 최소화 토글 옮기기, 앱 디자인 15가지와 색감, 머리줄 단추([문수네집 ▼]·Instagram·[커뮤니티&문의 ▼]·[EDUITIT ▼]), 익명 사용 통계(⚙ 설정에서 끌 수 있음)가 들어 있어요.
- **0.5.0-beta.11 (시험판)**: 접기 모드에서 창 크기가 어긋나던 것을 고쳤어요(창 크게 상태에서 접었다 펴기, 접힌 채 두 번 누르기·화면 위로 끌어 붙이기, 막대를 옮긴 뒤 펴기). [EDUITIT ▼]를 누르면 에듀잇티 사이트와 에듀잇티 쓰레드 단추가 펼쳐져요.
- **0.5.0-beta.10 (시험판)**: 이름이 나이스리모컨으로 바뀌었어요. 출결·누가기록을 직접 넣어 줘요([저장]은 선생님이 확인하고 눌러요). 켜면 화면 맨 위 가로 막대(미니 모드)로 시작하고, 접기 모드 막대는 모니터 좌우로 꽉 차요. 최소화 토글은 끌어서 옮길 수 있어요. 앱 디자인 15가지와 디자인별 색감을 고를 수 있어요(처음은 카툰·바다). 이 판부터 익명 사용 통계를 보내요. 아이디·이름·학교·학생 정보는 보내지 않고, ⚙ 설정에서 끌 수 있어요.
- **0.5.0-beta.1 (시험판)**: 출결·누가기록 줄을 넣었어요(도구 줄의 [출결·누가기록]으로 펼쳐요). 지금은 출결관리·행동특성및종합의견을 열어 두고, 선생님이 직접 고르거나 붙여넣는 과정을 학생 이름을 가린 파일로 이 PC에만 남기는 '배우기'까지 해요. 자동 채우기는 다음 버전에 들어가요. 업데이트 확인(⚙ 설정·트레이)도 이 판부터 들어 있어요.
